# 카카오톡 보내기 (PC 카카오톡 창 조작)

## 무엇을 하나

클로드 코드에게 "카톡으로 홍길동에게 '내일 회의 3시예요' 보내줘"라고 말하면,
내 PC에 켜 둔 **카카오톡 창을 프로그램이 직접 조작해서** 보낸다.

1. 이름으로 **검색**한다.
2. 대화방을 **연다**.
3. 열린 방 **제목이 말한 이름과 정확히 같은지** 확인한다(다르면 멈춘다).
4. 글 · 파일을 **보낸다**. `--yes` 를 붙이지 않으면 미리보기만 하고 보내지 않는다.
5. 보낸 뒤 화면을 캡처해 **정말 올라갔는지** 확인한다.

> 카카오 공식 API가 아니다. 사람이 마우스·키보드로 하는 일을 프로그램이 대신 하는 방식이다.
> 그래서 **PC 카카오톡이 켜져 있고 로그인돼 있어야** 하고, **Windows 에서만** 된다.

## 설치 (3단계)

1. 이 `kakao-send` 폴더를 통째로 `%USERPROFILE%\.claude\skills\` 안에 복사한다.
   (탐색기 주소창에 `%USERPROFILE%\.claude\skills` 를 넣으면 바로 열린다. 폴더가 없으면 만든다.)
   → 최종 위치: `%USERPROFILE%\.claude\skills\kakao-send\SKILL.md`
2. 필요한 파이썬 패키지를 설치한다(PowerShell):
   ```powershell
   pip install pywin32 pillow
   ```
   - `pywin32` — 윈도 창을 찾고 누르는 데 쓴다(`win32gui`, `win32api`, `win32con`, `win32process`, `win32clipboard`, `win32ui`).
   - `pillow` — 화면 캡처(`PIL`).
3. 클로드 코드를 새로 열고, PC 카카오톡을 켜서 로그인한 뒤 '채팅' 탭을 열어 둔다.
   잘 되는지 보려면: `python "$env:USERPROFILE\.claude\skills\kakao-send\scripts\kakao.py" status`
   → `"running": true` 가 나오면 준비 끝.

## 쓰는 법

클로드 코드에 그냥 말하면 된다.

- "카톡으로 홍길동에게 '내일 회의 3시예요' 보내줘"
- "홍길동한테 바탕화면에 있는 발표자료.pdf 카톡으로 보내줘"
- "나와의 채팅(내 이름)으로 이 사진 보내줘" — 처음엔 **나에게 보내기로 연습**하자.

클로드가 아래 명령을 차례로 쓴다(직접 쳐도 된다, **PowerShell** 에서). 출력은 JSON 한 줄.

```powershell
$k = "$env:USERPROFILE\.claude\skills\kakao-send\scripts\kakao.py"
$b = "$env:USERPROFILE\.claude\skills\kakao-send\scripts\kakao_bg.py"

python $k status                         # 카카오톡 켜짐 여부, 열린 대화방
python $k search "이름"                   # 검색 결과 화면 캡처(screenshot 경로의 그림으로 후보 확인)
python $k open "이름" --pick 1            # 검색 결과 1번째 방 열기
python $k peek "방 제목" --lines 30        # 최근 대화 + 방 화면 캡처(맞는 사람인지 확인)

# 보내기 — 마우스·키보드를 빼앗지 않는 방식(권장)
python $b send "방 제목" --text-file 글.txt                    # 미리보기만(안 보냄)
python $b send "방 제목" 사진1.png 자료.pdf --text-file 글.txt --yes   # 실제 전송
```

- 긴 글이나 한글은 `--text-file 글.txt`(UTF-8)로 넘기면 깨지지 않는다.
- 파일 여러 개를 한 번에 보내면 사진은 한 묶음으로 나가고, 파일이 다 올라간 뒤에 글이 나간다.
- `kakao_bg.py send` 가 안 되면 예전 방식 `python $k send "방 제목" 파일 --text-file 글.txt --yes`(마우스를 잠깐 씀)로 보낸다.
- `kakao_bg.py open` 은 카톡 검색창을 한 번이라도 연 뒤에만 된다. 안 되면 `kakao.py open` 을 쓴다.

### 안내 문구

보내는 모든 메시지 끝에 아래 문구가 자동으로 붙는다(받는 사람이 AI가 보낸 것을 알 수 있게).

```
-AI 비서가 대신 보낸 메시지입니다. 실수가 있을 수 있으니 양해 부탁드립니다.
```

- 문구를 바꾸려면 `scripts/kakao.py` 의 `SIGN = "..."` 한 줄을 고친다.
- 그 한 건만 빼려면 `kakao_bg.py send … --no-sign` (보낼 글이 있을 때만).

### (선택) 자주 보내는 서류를 한 번에 — `quick_doc.py`

`scripts/quick_doc.py` 위쪽 `DOCS` 표에 서류를 등록하면
`python -X utf8 "$env:USERPROFILE\.claude\skills\kakao-send\scripts\quick_doc.py" "방 제목" 서류키 --dry` 처럼 명령 하나로 보낼 수 있다.
처음엔 표가 비어 있으니 예시를 보고 직접 채운다. `--dry` 를 빼면 실제로 보낸다.

## 반드시 지킬 순서 (클로드가 따를 규칙)

1. **찾기** — `search "이름"` → 캡처를 본다. 결과가 **여러 개**면 멈추고 사용자에게 후보(방 이름 · 인원 · 마지막 대화 시각)를 보여 주고 고르게 한다.
2. **열고 확인** — `open` → `peek` 로 최근 대화와 프로필을 본다. 처음 보는 대화, 동명이인 의심, 개인에게 보내려는데 단톡방이 열린 경우 등 **이상하면 보내지 말고 묻는다.**
3. **미리보기** — `send` 를 **`--yes` 없이** 돌려 방 제목과 내용을 확정한다.
4. **사용자 확인** — "○○님(방 제목)께 이 글 / 파일 N개를 보냅니다. 보낼까요?" → **"응 · 보내" 같은 분명한 답을 받은 뒤에만** `--yes`. 확인은 건마다 받는다.
5. **보낸 뒤** — 결과의 `ok` 와 `screenshot` 캡처를 보고 알린다. `ok:false` 면 보냈다고 말하지 말고 캡처를 확인해 사실대로 알린다.

## 안전 규칙

- **보내기 전에 받는 사람과 내용을 사용자에게 꼭 확인받는다.** 카톡은 한 번 보내면 되돌리기 어렵다.
- **단체방 · 모르는 사람에게 대량 발송 금지.** 여러 방에 한꺼번에 보내는 기능은 일부러 넣지 않았다. 카카오가 자동 대량 발송을 막고 있어 **계정이 제한될 수 있다.** 여러 명에게 보낼 때는 한 명씩 확인하며 보낸다. 광고 · 스팸에 쓰지 않는다.
- 카카오 공식 API가 아니라 **PC 카톡 창을 조작하는 방식**이다. PC 카카오톡이 켜져 있고 로그인돼 있어야 하며, 화면이 잠기거나 카톡이 최소화돼 있으면 안 된다. **Windows 전용.**
- 카톡 업데이트로 화면 배치가 바뀌면 버튼 위치가 안 맞을 수 있다 → 아래 '안 될 때' 참고.
- 캡처는 `%TEMP%\kakao_send\` 에 쌓인다. 대화 내용이 담기므로 남에게 보내지 않는다.

### 코드에 들어 있는 안전장치

- `--yes` 없이는 절대 보내지 않는다(미리보기만).
- 받는 방 제목과 **정확히 같은** 대화방 창이 **딱 하나** 열려 있을 때만 보낸다.
- 카카오톡 창이 맨 앞에 온 게 확인되지 않으면 아무것도 누르지 않고 멈춘다(다른 창을 잘못 누르는 사고 방지).
- 사진 보기 · 확인 창 같은 다른 카톡 창이 떠 있으면 멈추고 캡처를 남긴다.
- 입력창에 쓰던 글(초안)이 있으면 지우지 않고 멈춘다.
- 파일 업로드가 끝난 것을 확인한 뒤에 글을 보낸다(순서 뒤섞임 방지). 확인 못 하면 글을 보내지 않는다.
- 대화 목록(말풍선)은 클릭하지 않는다(사진 보기 창이 열려 앞을 막는 사고 방지).

## 안 될 때

| 증상 | 원인 · 조치 |
|---|---|
| `"running": false` | PC 카카오톡을 켜고 로그인한다 |
| `맨 앞으로 가져오지 못해 멈췄습니다` | 화면 잠금, 다른 프로그램의 전체 화면, 카톡 확인 창이 떠 있음 → 정리하고 다시 |
| `채팅 탭이 아닙니다` | 카카오톡 왼쪽에서 말풍선 모양 '채팅' 탭을 눌러 둔다 |
| `검색창 없음` (kakao_bg open) | `kakao.py search "이름"` 을 한 번 돌린 뒤 다시, 또는 `kakao.py open` 사용 |
| 파일 아이콘 위치가 안 맞음 | 카톡 업데이트로 아이콘 줄이 바뀜 → `peek` 캡처로 위치를 다시 재서 `kakao_bg.py` 의 `post_click(h, 88, ch - 24)` · `kakao.py` 의 `attach_one` (88, -24) 를 고친다 |
| 검색 결과가 이상함 | 이름과 방 제목이 다를 수 있음(단톡방 이름 · 별명) → 카톡에 보이는 방 제목 그대로 말한다 |
| 오픈채팅방에 보내야 함 | 검색은 '채팅' 탭(일반 대화)에서만 한다 → 오픈채팅은 코드 수정 필요 |
